# content-boost-media

Public hosting for images that Claude imports into Hopper with the Link option (Hopper fetches the image by URL, so no file picker is needed).

- One folder per client (ZAC, MARK, ARJUN, STEVEN, MATT, JAYDON, SALMAN).
- Inside it, one folder per post: YYYY-MM-DD_slug/.
- Link format: https://raw.githubusercontent.com/zjdk-2026/content-boost-media/main/CLIENT/FOLDER/FILE.png
- Everything here is public. Only add media that is approved to go public, and delete a post folder after it is published.
